プライバシーポリシー

最終更新日：2026年11月2日

本アプリ「ポケット文学館」（旧名「あらすじで読む日本文学」。Android 版と iPhone・iPad 版があります）は、ユーザーの個人情報を直接取得することはありません。 アカウント登録は不要で、氏名・メールアドレス・電話番号・位置情報などの入力を求めることもありません。

広告・利用状況の解析について

本アプリには広告はなく、広告配信サービスも利用していません。広告識別子（広告ID）の取得や利用も行わず、 ほかの会社のアプリやウェブサイトをまたいだ追跡（トラッキング）もしません。 利用状況の解析やクラッシュの報告のためのサービスも利用していません。

端末内に保存される情報

本アプリの利用にともなって作成される次の情報は、すべてお使いの端末内にのみ保存されます。 当方のサーバーは存在せず、これらが当方や第三者へ送信されることはありません。

  • アプリの設定（テーマ、本文のフォント、リーダーの表示設定、読書リマインダーなど）
  • お気に入りに登録した作品・作家、閲覧履歴
  • 読書記録（読書時間、読み終えた作品、あらすじを読んだ作品）
  • 青空文庫からダウンロードした作品の本文と、そのしおり・保存したフレーズ
  • ダウンロードした本文用のフォント
  • ワードクラウド（本文の頻出語）の解析結果

これらはアプリを削除すると同時に失われます。 ダウンロードした本文は、アプリ内の「設定」→「データ管理」からいつでも個別に、または一括で削除できます。

バックアップについて

アプリの設定・お気に入り・閲覧履歴・読書記録は、端末を買い替えたときに記録を引き継げるよう、 端末の標準のバックアップに含まれることがあります。保存先はユーザーご自身のアカウントであり、 当方がその内容を閲覧することはできません。バックアップの有効・無効は端末の「設定」から変更できます。 なお、ダウンロードした本文とフォントはデータ量が大きいためバックアップの対象外としています。

  • Android … 自動バックアップ（Google アカウント）
  • iPhone・iPad … iCloud バックアップ（Apple アカウント）

外部サイトへの通信について

本アプリは、ユーザーが操作したときにのみ外部サイトへ接続します。 接続の際に、ユーザーを特定できる情報を送ることはありません。

  • 作品の本文をダウンロードするとき、および「青空文庫」のボタンを押したとき … 青空文庫（www.aozora.gr.jp）
  • 本文用のフォントをダウンロードするとき … フォントの配布元（raw.githubusercontent.com、cdn.jsdelivr.net）
  • 作家詳細の Wikipedia ボタンを押したとき … Wikipedia（ja.wikipedia.org）
  • 文学賞・文学館の画面のリンクを押したとき … リンク先のウェブサイト（文学館の公式サイトなど）、 または地図サービス（Google マップ）
  • 画面上の文字を選択して「Web検索」を選んだとき（Android 版のみ） … 端末の検索アプリ、 または Google 検索（ブラウザ）

これらの接続にともない、IP アドレスなどの一般的な通信情報が接続先に記録される場合があります。 なお、収録している作品はいずれも著作権保護期間の満了した作品で、青空文庫の公開データを利用しています。

音声読み上げについて

本アプリの読み上げ機能は、お使いの端末の音声読み上げの機能を利用します。 本アプリが読み上げた音声を録音・保存することはありません。

  • Android … 端末にインストールされているテキスト読み上げ（TTS）エンジンを利用します。 端末の読み上げエンジンによっては、音声を合成するために読み上げ対象の文章が そのエンジンの提供元（Google など）のサーバーへ送信される場合があります。 送信の有無や取り扱いは、端末の読み上げエンジンの設定およびその提供元のプライバシーポリシーに従います。
  • iPhone・iPad … iOS・iPadOS に組み込まれている音声合成の機能を利用します。

アプリが利用する権限

本アプリが利用する権限は次のとおりです。 位置情報・連絡先・カメラ・マイクへのアクセス権限は一切要求せず、写真やファイルを読み取ることもありません。

Android

  • インターネット接続 … 本文とフォントのダウンロードに使用します。
  • 通知（Android 13 以降） … 読み上げ中に再生・一時停止・停止の操作を通知として表示するため、 および読書リマインダーを有効にしたときにお知らせを送るために使用します。許可しなくてもアプリは利用できます。
  • フォアグラウンドサービス（メディア再生） … 画面を消したり他のアプリに切り替えたりしても 読み上げを続けるために使用します。読み上げ中のみ動作し、読み上げを停止すると終了します。
  • ストレージ（Android 9 のみ） … 名文の画像を保存するときに、端末の「Pictures」フォルダへ画像を置くためだけに使用します。

iPhone・iPad

  • 通知 … 読書リマインダーを有効にしたときに、お知らせを送るためだけに使用します。
  • 写真への追加 … 名文の画像の共有で「画像を保存」を選んだときだけ求めます。 写真ライブラリへ画像を追加するだけの権限で、ほかの写真を本アプリが見ることはできません。
  • バックグラウンドでの音声再生 … 画面を消したり他のアプリに切り替えたりしても読み上げを続けるために使用します。

プライバシーポリシーの変更について

本ポリシーの内容は、法令の変更やアプリの機能追加にともなって改定されることがあります。 重要な変更がある場合は、本ページの最終更新日を改めたうえで掲載します。
